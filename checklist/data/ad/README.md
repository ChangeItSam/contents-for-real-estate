# Abu Dhabi data (checklist/ad.html and the DealPro Agent Abu Dhabi tabs)

Abu Dhabi files use the same layout as the Dubai files in `checklist/data/`, so the same page code works for both emirates.
Until the ADREC (Abu Dhabi Real Estate Centre) sales export is loaded, most files here are empty placeholders.

- `projects_ad.json`: the project list the Abu Dhabi test searches (`n` name, `d` district, `dev` developer, `s` sales count).
- `psf.json`: price per sq ft by project / district (same layout as `../psf.json`), built from ADREC sales.
- other files: empty placeholders so the page loads cleanly.

ADREC export: https://adrec.gov.ae/en/market-data (sales table, Excel export), uploaded to Sam's Drive folder "DealPro - Abu Dhabi ADREC data".
